# GRURegionais

Sistema do ecossistema de projetos para gestao e operacao de GRU Regionais.

## Estrutura do Projeto
- src/: Codigo-fonte da aplicacao
- docs/: Documentacao tecnica e especificacoes
- 	ests/: Baterias de testes automatizados
- scripts/: Scripts utilitarios e operacionais
- session_log/: Historico de sessoes consolidadas
