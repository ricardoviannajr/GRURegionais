## 2. Notas de Padronização e Resolução de Códigos ICAO

Durante a auditoria junto à base de dados do DECEA/AISWEB, foram identificadas transições cadastrais relevantes frente aos registros iniciais de editais:

1. **Barreirinhas (MA):** O código ativo no AISWEB é **`SSRS`** (CIAD: `MA0008`). O código `SBRR` constante em algumas tabelas históricas do bloco de concessões refere-se a um registro legado/reestruturado pelo DECEA.
2. **Serra da Capivara / São Raimundo Nonato (PI):** O código ativo no AISWEB é **`SWKQ`** (CIAD: `PI0007`). O código `SWSR` corresponde a um heliponto privado no Maranhão na base atual do ROTAER.
3. **Porto Alegre do Norte (MT):** O aeródromo municipal homologado no AISWEB possui indicativo **`SDH2`** (CIAD: `MT0662`), com pista asfáltica de 1.600 x 18m. O código `SWPQ` corresponde à pista privada da Fazenda Piraguassu (piso de cascalho).
